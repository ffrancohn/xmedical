# Prototipo Atlas interactivo (aislado)

Demo estática del flujo **Objeto → Exploración → Acción** sin Django.

```bash
# Desde la raíz del repo
python3 -m http.server 8765 --directory deck/atlas-interactive
```

Abrir `http://localhost:8765/`.

Cuando existan WebP en `designs/atlas-interactive/`, enlazarlos aquí antes de copiar a `static/atlas-interactive/assets/`.
