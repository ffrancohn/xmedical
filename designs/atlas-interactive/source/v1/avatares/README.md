# XMedical — 10 avatares completos

Se entrega una ilustración completa por personaje sin máscaras automáticas que pierdan piernas, brazos o cabeza.

**Limitación de calidad:** los personajes se extrajeron de una lámina; conservan su fondo original y tienen resolución adecuada para tarjetas pequeñas (240×330), no para zoom grande. Este paquete NO ofrece transparencia perfecta ni generación individual nativa.

Los identificadores son genéricos, no datos clínicos. Incluye manifest.json. Para producción definitiva, cada personaje debe generarse por separado en alta resolución con fondo transparente.
